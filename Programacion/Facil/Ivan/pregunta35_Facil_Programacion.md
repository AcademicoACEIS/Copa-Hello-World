# Pregunta 35 — Completar pseudocódigo

**Nivel:** Fácil · **Puntos:** 15 · **Tipo:** COMP  
**Tema:** 3.3 Operaciones y asignación

## Enunciado

Completa el pseudocódigo para calcular el doble de un número ingresado.

```text
READ numero
doble = _____
WRITE doble
```

## Respuesta

`numero * 2` — se multiplica el dato leído por dos y se muestra el resultado.
