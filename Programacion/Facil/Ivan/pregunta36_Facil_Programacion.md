# Pregunta 36 — Completar pseudocódigo

**Nivel:** Fácil · **Puntos:** 15 · **Tipo:** COMP  
**Tema:** 4.2 Condicional simple

## Enunciado

Completa el pseudocódigo para mostrar "Par" cuando el número sea divisible entre 2.

```text
READ numero
IF numero MOD 2 _____ 0 THEN
  WRITE _____
END IF
```

## Respuesta

`==` / `"Par"` — el residuo de dividir un número par entre 2 es cero.
