# Pregunta 38 — ¿Qué imprime?

**Nivel:** Fácil · **Puntos:** 15 · **Tipo:** IMP  
**Tema:** 4.2 Condicional simple

## Enunciado

¿Qué imprime si `temperatura = 30`?

```text
IF temperatura > 25 THEN
  WRITE "Calor"
ELSE
  WRITE "Fresco"
END IF
```

## Respuesta

Imprime `Calor` — 30 es mayor que 25, así que se ejecuta la primera rama.
