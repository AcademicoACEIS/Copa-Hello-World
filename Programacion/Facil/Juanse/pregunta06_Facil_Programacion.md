# Pregunta 6 — ¿Qué imprime?

**Nivel:** Fácil · **Puntos:** 15 · **Tipo:** IMP  
**Tema:** 3.3 Operadores aritméticos

## Enunciado

¿Qué imprime el siguiente pseudocódigo?

```text
a = 10
b = 3
WRITE a MOD b
WRITE a DIV b
```

## Respuesta

Imprime 1 (residuo de 10÷3) y luego 3 (división entera de 10÷3).
