# Pregunta 10 — Completar pseudocódigo

**Nivel:** Fácil · **Puntos:** 15 · **Tipo:** COMP  
**Tema:** 4.2 If-else

## Enunciado

Completa el pseudocódigo para mostrar "Aprobado" si nota >= 60 y "Reprobado" en caso contrario.

```text
READ nota
IF nota _____ 60 THEN
  WRITE _____
_____
  WRITE "Reprobado"
END IF
```

## Respuesta

IF nota >= 60 THEN   /   WRITE "Aprobado"   /   ELSE
