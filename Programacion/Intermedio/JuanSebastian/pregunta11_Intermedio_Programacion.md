# Pregunta 11 — ¿Qué imprime?

**Nivel:** Medio · **Puntos:** 20 · **Tipo:** IMP  
**Tema:** 5.2 Ciclo while

## Enunciado

¿Qué imprime el siguiente pseudocódigo?

```text
i = 1
suma = 0
WHILE i <= 5 DO
  IF i MOD 2 == 0 THEN
    suma = suma + i
  END IF
  i = i + 1
END WHILE
WRITE suma
```

## Respuesta

Imprime 6 — suma solo los números pares entre 1 y 5: 2 + 4 = 6.
