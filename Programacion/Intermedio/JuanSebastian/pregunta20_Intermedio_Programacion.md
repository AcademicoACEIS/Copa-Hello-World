# Pregunta 20 — Completar pseudocódigo

**Nivel:** Medio · **Puntos:** 20 · **Tipo:** COMP  
**Tema:** 4.3 Switch-case

## Enunciado

Completa el switch para imprimir el tipo de triángulo según lados iguales (0=Escaleno, 2=Isósceles, 3=Equilátero).

```text
READ lados_iguales
SWITCH lados_iguales
  CASE _____:
    WRITE "Escaleno"
  CASE 2:
    WRITE _____
  CASE 3:
    WRITE "Equilátero"
  DEFAULT:
    WRITE _____
END SWITCH
```

## Respuesta

CASE 0   /   WRITE "Isósceles"   /   WRITE "Valor no válido"
