# Pregunta 47 — Completar pseudocódigo

**Nivel:** Medio · **Puntos:** 20 · **Tipo:** COMP  
**Tema:** 5.1 For + acumulador

## Enunciado

Completa el pseudocódigo para sumar los números del 1 al N, inclusive.

```text
READ N
suma = 0
FOR i = 1 TO N DO
  suma = _____
END FOR
WRITE suma
```

## Respuesta

`suma + i` — en cada iteración se agrega el valor actual de `i` al acumulador.
