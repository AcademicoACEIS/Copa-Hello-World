# Pregunta 50 — ¿Qué imprime?

**Nivel:** Medio · **Puntos:** 20 · **Tipo:** IMP  
**Tema:** 5.2 While + acumulador

## Enunciado

¿Qué imprime el siguiente pseudocódigo?

```text
i = 1
suma = 0
WHILE i <= 4 DO
  suma = suma + i
  i = i + 1
END WHILE
WRITE suma
```

## Respuesta

Imprime `10` — acumula `1 + 2 + 3 + 4` antes de que `i` llegue a 5.
