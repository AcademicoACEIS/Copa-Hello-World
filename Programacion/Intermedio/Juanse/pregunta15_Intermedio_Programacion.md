# Pregunta 15 — Completar pseudocódigo

**Nivel:** Medio · **Puntos:** 20 · **Tipo:** COMP  
**Tema:** 5.2 While con centinela

## Enunciado

Completa el pseudocódigo para sumar números ingresados por el usuario hasta que ingrese 0.

```text
suma = 0
READ numero
WHILE numero _____ DO
  suma = _____
  READ numero
END WHILE
WRITE suma
```

## Respuesta

WHILE numero != 0 DO   /   suma = suma + numero
