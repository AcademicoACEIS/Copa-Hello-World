# Pregunta 1 — Selección múltiple

**Nivel:** Fácil · **Puntos:** 15 · **Tipo:** SM  
**Tema:** 1.3 Tipos de lenguajes

## Enunciado

¿Cuál de los siguientes lenguajes es interpretado?

- A) C
- B) C++
- C) Python
- D) Java

## Respuesta

C) Python — se ejecuta línea por línea sin generar un ejecutable previo.
