# Pregunta 5 — Selección múltiple

**Nivel:** Fácil · **Puntos:** 15 · **Tipo:** SM  
**Tema:** 4.3 Switch-case

## Enunciado

¿Qué estructura se usa cuando se quieren evaluar múltiples casos de un mismo valor de forma ordenada?

- A) if simple
- B) while
- C) switch-case
- D) for

## Respuesta

C) switch-case — permite evaluar múltiples valores posibles de una variable de forma limpia.
