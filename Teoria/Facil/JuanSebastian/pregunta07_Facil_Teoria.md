# Pregunta 7 — Verdadero / Falso

**Nivel:** Fácil · **Puntos:** 15 · **Tipo:** VF  
**Tema:** 3.2.1 Scope

## Enunciado

Una variable declarada dentro de un IF puede ser usada libremente fuera de ese bloque en cualquier lenguaje.

## Respuesta

Falso — en la mayoría de lenguajes el scope limita el uso de una variable al bloque donde fue declarada.
