# Pregunta 3 — Selección múltiple

**Nivel:** Fácil · **Puntos:** 15 · **Tipo:** SM  
**Tema:** 3.1 Tipos de datos primitivos

## Enunciado

¿Cuál de las siguientes variables almacena correctamente un número con decimales?

- A) entero = 3.14
- B) texto = 3.14
- C) real = 3.14
- D) booleano = 3.14

## Respuesta

C) real = 3.14 — el tipo correcto para números con decimales es float o real.
