# Pregunta 45 — Verdadero / Falso

**Nivel:** Medio · **Puntos:** 20 · **Tipo:** VF  
**Tema:** 4.3 Switch-case

## Enunciado

En una estructura `switch-case`, varios casos pueden ejecutar el mismo bloque si el lenguaje o pseudocódigo permite agruparlos.

## Respuesta

Verdadero — se pueden agrupar alternativas que comparten el mismo resultado, evitando repetir instrucciones.
