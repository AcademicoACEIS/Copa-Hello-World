# Pregunta 19 — Selección múltiple

**Nivel:** Medio · **Puntos:** 20 · **Tipo:** SM  
**Tema:** 3.5 Operadores lógicos

## Enunciado

¿Cuál es el resultado de: (TRUE OR FALSE) AND (FALSE OR FALSE)?

- A) TRUE
- B) FALSE
- C) ERROR
- D) Depende del lenguaje

## Respuesta

B) FALSE — (TRUE OR FALSE) = TRUE, luego TRUE AND (FALSE OR FALSE) = TRUE AND FALSE = FALSE.
