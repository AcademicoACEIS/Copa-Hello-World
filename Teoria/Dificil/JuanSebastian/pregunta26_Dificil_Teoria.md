# Pregunta 26 — Verdadero / Falso

**Nivel:** Difícil · **Puntos:** 30 · **Tipo:** VF  
**Tema:** 5.4 Ciclos anidados

## Enunciado

Es posible usar BREAK dentro del ciclo interno para salir también del ciclo externo directamente.

## Respuesta

Falso — BREAK solo sale del ciclo más inmediato donde está. Para salir del externo se necesita una variable bandera u otra estrategia.
