# Pregunta 42 — Diagrama de flujo

**Nivel:** Fácil · **Puntos:** 15 · **Tipo:** DF  
**Tema:** 4.2 If-else

## Enunciado

Dibuja el diagrama de flujo de un algoritmo que lea una nota de 0 a 100 e indique "Aprobado" si es al menos 60 o "Reprobado" en caso contrario.

## Respuesta

Debe incluir: Inicio → READ nota → rombo `nota >= 60` → sí: WRITE "Aprobado" / no: WRITE "Reprobado" → Fin.
