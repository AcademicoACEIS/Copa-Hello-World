# Pregunta 41 — Diagrama de flujo

**Nivel:** Fácil · **Puntos:** 15 · **Tipo:** DF  
**Tema:** 4.1 Decisión simple

## Enunciado

Dibuja el diagrama de flujo de un algoritmo que lea un número e indique si es positivo o negativo. Considera que el número no será cero.

## Respuesta

Debe incluir: Inicio → READ número → rombo `número > 0` → sí: WRITE "Positivo" / no: WRITE "Negativo" → Fin.
