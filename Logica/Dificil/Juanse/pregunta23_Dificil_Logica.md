# Pregunta 23 — Diagrama de flujo

**Nivel:** Difícil · **Puntos:** 30 · **Tipo:** DF  
**Tema:** 5.4 + 4.4 Ciclos anidados y condicional

## Enunciado

Dibuja el diagrama de flujo completo: el usuario ingresa N filas. El algoritmo imprime una pirámide donde fila i tiene i asteriscos. Las filas pares usan "#" en lugar de "*".

## Respuesta

Debe mostrar: Inicio → READ N → FOR i=1 TO N → rombo i MOD 2==0 → sí: ciclo interno WRITE # / no: ciclo interno WRITE * → salto de línea → Fin. Ciclos anidados con flechas de retorno claramente trazadas.
