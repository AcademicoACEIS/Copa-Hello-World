# Pregunta 53 — Diagrama de flujo

**Nivel:** Medio · **Puntos:** 20 · **Tipo:** DF  
**Tema:** 5.1 For + conteo

## Enunciado

Dibuja el diagrama de flujo de un algoritmo que lea 5 números y cuente cuántos son positivos. Incluye el contador y la salida final.

## Respuesta

Debe incluir: Inicio → `contador=0`, `i=1` → rombo `i<=5` → READ número → rombo `número>0` → sí: `contador=contador+1` → incrementar `i` y volver al primer rombo → WRITE contador → Fin.
