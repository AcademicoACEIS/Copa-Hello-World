# Pregunta 54 — Diagrama de flujo

**Nivel:** Medio · **Puntos:** 20 · **Tipo:** DF  
**Tema:** 4.4 Condiciones compuestas

## Enunciado

Dibuja el diagrama de flujo de un algoritmo que lea un número e indique "Dentro" si está entre 10 y 20, incluidos ambos extremos; de lo contrario, debe indicar "Fuera".

## Respuesta

Debe incluir: Inicio → READ número → rombo `número >= 10 AND número <= 20` → sí: WRITE "Dentro" / no: WRITE "Fuera" → Fin.
