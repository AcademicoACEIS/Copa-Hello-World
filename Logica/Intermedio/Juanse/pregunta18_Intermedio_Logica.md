# Pregunta 18 — Diagrama de flujo

**Nivel:** Medio · **Puntos:** 20 · **Tipo:** DF  
**Tema:** 5.3 For + acumulador

## Enunciado

Dibuja el diagrama de flujo de un algoritmo que calcule la suma de los primeros N números naturales. El usuario ingresa N. Incluye inicio, entrada, ciclo, acumulación y salida del resultado.

## Respuesta

Debe incluir: Inicio → READ N → suma=0, i=1 → rombo i<=N → suma=suma+i, i=i+1 (vuelve al rombo) → WRITE suma → Fin.
